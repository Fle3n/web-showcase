# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Potential clients evaluating Fle3n's ability to create working websites and business tools. Visitors to each concept should be able to complete a realistic local demonstration.

## Product Purpose
Three complete, visually distinct portfolio websites. They should demonstrate design, responsive engineering and useful interactive assistants, rather than repeat one landing-page template.

## Operating Context
Windows-hosted local Node server at TCP ports 1051, 1052 and 1053, accessible by port forwarding. Source is published to Fle3n/web-showcase on GitHub.

## Capabilities and Constraints
Coffee: product selection, customization, cart and recommendation assistant. Clinic: service guidance, date/time planning and calendar export, without medical advice. Automation: request processing, project brief and calculation. All are demonstrations, not real customer transactions or medical bookings. Telegram links lead only to https://t.me/fle3n. No WhatsApp. No invented customers, testimonials or business performance claims. No interest-based finance, gambling, alcohol or other explicitly prohibited business domains.

## Brand Commitments
The user rejected both previous visual versions and requested rebuilding all three sites. On 2026-11-06 the user delegated theme and design decisions and chose code-first implementation with a separate visual review. Existing project uses buildless HTML, CSS and ES modules; retain that deploy-compatible stack.

## Evidence on Hand
Existing runnable concepts and user feedback screenshot showing the rejected ticker. No real client endorsements, verified clinic or physical cafe, or live LLM connection.

## Product Principles
- Show useful interaction in the first viewport.
- Distinct subject-specific composition on each site.
- Content remains visible while motion adds feedback.
- Preserve meaningful behavior while replacing the rejected visual system.
